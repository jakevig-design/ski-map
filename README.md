# Ski Map

Every ski area Jake has skied, on one map: a digital version of the framed, pinned "Ski Areas" posters. Public and read-only; Jake edits it when signed in.

Live at **https://ski.jvtestspace.com**. Build spec: `reference/BUILD_SPEC.md`; visual reference: `reference/mockup.html`. Choices the spec left open, or that changed it: `DECISIONS.md`. Manual steps outstanding: `BLOCKERS.md`.

## Running it

```sh
npm install
cp .env.example .env.local   # anon key only
npm run dev                  # http://localhost:5173
npm run build
```

Pushes to `main` deploy to production on Vercel.

## How it fits together

- **Map data is static**, built once and committed under `public/data/`:
  - `node scripts/build-geo.mjs` — Natural Earth 10m land, admin-1 and lakes → TopoJSON (`land.json`, `admin.json`, `lakes.json`, ~480 KB).
  - `node scripts/build-ski-areas.mjs` — every operating downhill ski area in the US, Canada and Mexico from OpenSkiMap → `ski-areas.json`.
  - Downloads are cached in `.cache/` (gitignored).
- **Jake's mountains and trips** live in Supabase (`ski_mountains`, `ski_trips` in the shared project `xdmhyjofbbtmjqprjsxj`). Anyone can read; RLS lets only `jakevig@gmail.com` write. Migrations are in `supabase/migrations/`, run in order in the SQL editor:
  - `001_ski_schema.sql` — tables and policies
  - `002_seed.sql` — the 29 mountains (generated by `scripts/build-seed.mjs` from `scripts/seed-data.mjs`)
  - `003_openskimap_ids.sql` — links them to OpenSkiMap (generated by `scripts/match-openskimap.mjs`)
- **Editing:** sign in at `/login` (not linked anywhere). The editor UI appears only for Jake's account, but RLS is the actual lock.
- **Code:** `src/components/MapView.tsx` draws the map with d3 (projection, zoom, pins, label collision); `Rail.tsx` is the stats, search and list; `Card.tsx` the mountain card and editor; `src/lib/useMountains.ts` loads data and does optimistic writes.

Map data © OpenStreetMap contributors (ODbL), OpenSkiMap, Natural Earth.
